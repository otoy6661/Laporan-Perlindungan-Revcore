# Indeks Laporan RevCore

Repositori ini menyimpan laporan riset dan teknis RevCore. Setiap paket laporan
dipertahankan sebagai arsip; laporan final lama tidak dihapus saat laporan baru
dipublikasikan.

## Paket laporan

| Paket | Tanggal | Lokasi | Isi |
|---|---|---|---|
| BE-10 — Deep Technical Research: ADX + 3D Chart Graph + ECU Software | 17 November 2026 | [`BE-10/`](BE-10/) | Laporan lengkap, register status, katalog 45 kanal live data, manifest 552 entri, skrip analisis, hasil prototipe 26/26 |
| BE-09 — External ECU Research | 2026 | root | Laporan akhir, ringkasan eksekutif, register status, hasil prototipe, rekomendasi integrasi, prioritas riset, gap analysis |

## Prinsip publikasi

- Publikasi hanya dilakukan setelah pemilik proyek memilih UPLOAD.
- File sumber laporan tidak diubah, dipindah, atau dihapus.
- Laporan final terdahulu tidak diganti tanpa persetujuan pemilik.
- Source donasi, kredensial, kunci, dan nilai lisensi tidak dipublikasikan.
